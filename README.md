# Aether X1 Pro — Technology Product Promotional Website

A responsive promotional landing page for a flagship smartphone built with pure HTML, CSS, and JavaScript.

## Included Sections
- **Hero & Interactive Product Preview**: Switch between Obsidian Black, Titanium Silver, and Alpine Blue finishes in real time.
- **Feature Highlights & Camera Spotlight**: Key hardware cards and an optical system overview.
- **Interactive Specifications**: Tabbed specs covering Performance & Display, Camera & Video, Battery & Connectivity, and Design & Box Contents.
- **Pricing Comparison**: Three storage tiers in INR (256 GB, 512 GB, 1 TB) with one-click jump to the configurator.
- **Purchase Configurator & Shopping Bag**: Pick finish, storage, and AetherCare+ protection with live pricing, slide-out shopping bag drawer, and `localStorage` persistence.
- **Customer Reviews**: Verified buyer reviews plus a working review submission form with star ratings.

## How to Run
1. Extract `tech-product-website.zip`.
2. Open `index.html` in any modern web browser.
